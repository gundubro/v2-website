# Skydda — Attack and Defend

An interactive Skydda website prototype built around one reversible, scroll-driven security narrative.

The same enterprise topology moves through environment, telemetry noise, offensive discovery, remediation,
defensive investigation, clarity, and one unified security context. Interface copy remains semantic HTML while
Three.js renders the persistent information world and GSAP ScrollTrigger choreographs the story.

## Local development

```bash
npm install
npm run dev
```

Open `http://localhost:3000`.

## Validation

```bash
npm run build
npm test
```

The experience includes desktop and mobile layouts, keyboard-accessible controls, a reduced-motion presentation,
an evidence disclosure, and a demo-request prototype.
